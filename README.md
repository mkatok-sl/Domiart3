# Gorilla — огляд казино (Бельетаж)

Односторінковий партнерський лендинг: React 19 + TypeScript + Tailwind CSS v4 + shadcn/ui + wouter.
Збирається у статичні файли з відносними шляхами (`./assets/...`) і працює як у корені домену,
так і в підпапці GitHub Pages (`https://username.github.io/repository/`).

## Команди

```bash
npm ci            # встановлення залежностей
npm run dev       # локальний сервер розробки
npm run build     # перевірка типів + продакшн-збірка в dist/
npm run preview   # перегляд зібраної версії
```

## Деплой на GitHub Pages

1. Завантажте проєкт у репозиторій (гілка `main`).
2. Settings → Pages → Source: **GitHub Actions**.
3. Workflow `.github/workflows/deploy.yml` збере сайт і опублікує `dist/` при кожному push.

Ручний варіант: `npm run build` і завантажте вміст `dist/` (разом із `.nojekyll` та `404.html`).

Базовий шлях визначається автоматично (`src/lib/base-path.ts`): за URL зібраного бандла,
а для `*.github.io` — за назвою репозиторію. Перебудовувати під конкретну підпапку не потрібно.

## Де редагувати контент

Усі дані й тексти — у `src/data/content.ts`:

- `CASINOS_DATA` — масив казино (рейтинг, бонус, вейджер, виплати, плюси/мінуси, логотип).
  Щоб додати бренди, допишіть об'єкти: картки й таблиця порівняння з'являться автоматично.
- `SITE`, `AUTHOR`, `REVIEWS_DATA`, `FAQ_DATA` та тексти розділів.
- `**жирний**` у будь-якому тексті перетворюється на `<strong>` через `formatText()`.

## Перед публікацією замініть

- [ ] `affiliateUrl` у `CASINOS_DATA` — ваше трекінгове посилання.
- [ ] `bonus.promoCode` — ваш партнерський промокод (або залиште `undefined`).
- [ ] `AUTHOR` — реальний автор огляду (E-E-A-T).
- [ ] `REVIEWS_DATA` — реальні відгуки; приберіть `isSample: true` (інакше показується мітка «Приклад»).
- [ ] `SITE.editorEmail` — контактна пошта редакції.
- [ ] Звірте умови бонусу, ліміти, банки та канали підтримки з gorilla.ua і реєстром PlayCity.
- [ ] За потреби додайте `<link rel="canonical">` в `index.html`.

## Шрифти

Cinzel і Plus Jakarta Sans не містять базової кирилиці, тому для українського тексту
браузер автоматично бере Playfair Display (заголовки) та Manrope (інтерфейс).
Lora (основний текст) кирилицю підтримує. Усі шрифти вбудовані через @fontsource, без зовнішніх запитів.
